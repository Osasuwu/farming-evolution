# pr-assets

Кадры для PR и задач Farming Evolution: скриншоты игры, сделанные сценариями из `tools/scenarios/`
основного репозитория. Это не ассеты мода: в `main` и в jar они не попадают.

Порядок (то же сказано в `AGENTS.md`, раздел «Кадры в PR»):

- Кадр лежит по пути `pr-<N>/<имя>.png`, где `<N>` — номер PR.
- В тексте PR кадр вставляется картинкой по ссылке на коммит, а не на ветку:
  `https://raw.githubusercontent.com/Osasuwu/farming-evolution/<sha коммита>/pr-<N>/<имя>.png`
- Кадр добавляется через API GitHub, локальный коммит в этой ветке не делается и хук
  `pre-commit` не обходится: ему в ветке-сироте нет `checks/`. Тело запроса — JSON-файл с
  полями `branch` (`pr-assets`), `message` и `content` (кадр в base64), потому что кадр в
  аргументе командной строки не помещается (`Argument list too long`):
  `gh api --method PUT repos/Osasuwu/farming-evolution/contents/pr-<N>/<имя>.png --input <файл.json> --jq .commit.sha`.
  Команда печатает sha коммита для ссылки.
- Ветка только дополняется: `--force` и удаление запрещены, старые кадры не переписываются.
- В ветке нет ничего, кроме кадров и этого файла; файлов из `main` здесь нет.
- Ветка не имеет общей истории с `main`; `verify` на пуш в неё не запускается.
